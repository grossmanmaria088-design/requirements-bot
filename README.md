# Telegram-бот для сбора требований к ПО

Бот помогает системным и бизнес-аналитикам структурировать требования к программному обеспечению.

## Возможности
- Добавление функциональных и нефункциональных требований
- Приоритизация (высокий, средний, низкий)
- Просмотр всех требований
- Статистика по требованиям
- Экспорт в TXT-файл

## Технологии
- Python 3.14
- Aiogram 3.x
- FSM (машина состояний)
- JSON для хранения данных

## Установка
1. `pip install aiogram python-dotenv`
2. Создайте файл `.env` с токеном бота: `BOT_TOKEN=ваш_токен`
3. Тг канал @BotFather
4.Запустите: `python main.py`
